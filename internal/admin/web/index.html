iOS: enrollment

MDM -
An iOS device is erased and supervised by the agent of its host (./zebrunner.sh mdm supervise <device>), a supervised one enrolled over USB (./zebrunner.sh mdm enroll <device>) with the profile of /mdm/enroll (a one-time SCEP challenge per profile). The agent also recovers a device that lost MDM and turns Developer Mode on: neither has an MDM command.

Android: Headwind MDM

Server -
Agent APK -
The agent is the device owner, set over adb by ./zebrunner.sh mdm enroll <device> on the host of the device: no factory reset, no account (Google) on the device. It keeps the system launcher, grants no permission and installs nothing by itself, always forbids safe mode. adb alone cannot remove it: the command Release the device or ./zebrunner.sh mdm release.
